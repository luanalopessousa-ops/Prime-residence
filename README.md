# Prime Residence | Imobiliária

Site demonstrativo de imobiliária com anúncios de imóveis, filtros e galeria de fotos.

> **Projeto demonstrativo de estudos em desenvolvimento Front-End.** Não representa um cliente real.

## 🛠️ Tecnologias utilizadas

## ▶️ Como visualizar

1. Clique em **Code → Download ZIP** para baixar o repositório.
2. Extraia os arquivos.
3. Abra o arquivo `index.html` no navegador ou use o Live Server do VS Code.

## 📂 Organização

- `index.html`: página inicial.
- `style.css`: estilos visuais.
- Arquivos `.js`: funcionalidades interativas (quando presentes).
- `img/`: imagens utilizadas no site (quando presentes).
- `screenshots/`: capturas para apresentação no GitHub.
